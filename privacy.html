Privacy Policy

Effective date: October 13, 2026

This policy describes the personal-use “VPS Encrypted Backup” utility and its public informational website. The utility is operated by the owner of this GitHub repository to back up databases from a privately managed server to the operator's Google Drive.

Data accessed

The backup workflow uses Google OAuth with the drive.file scope to create, read, and manage the Google Drive files that the application creates or that the operator explicitly authorizes for it. The workflow handles encrypted backup archives and the Google OAuth credentials needed for its operation. It does not request permission to browse or manage all Google Drive files.

How data is used

Google Drive access is used to upload encrypted backup archives, retrieve them to check file integrity and restore readiness, and manage backup files when explicitly instructed by the operator. Database backup archives are encrypted on the server before being sent to Google Drive. The encryption passphrase is managed separately from the stored archives.

Storage and security

Encrypted backup archives reside in the operator's own Google Drive account. Google OAuth access and refresh tokens are held locally in a restricted rclone configuration on the operator's VPS. Unencrypted source backups can also be retained locally on the VPS for recovery purposes; they are not intentionally uploaded to this website or GitHub repository. The operator controls access to the server and Google Drive account.

Sharing

The backup workflow does not sell personal information or intentionally share backup archives with third parties. Google processes encrypted backup files as the Drive storage provider. The public website is hosted by GitHub Pages, whose hosting infrastructure may process technical connection information under GitHub's privacy statement. This site contains no analytics scripts or tracking pixels added by the operator.

Retention and deletion

Backup archives are retained until the operator deletes them or applies a separately configured retention policy; no fixed automatic deletion period is promised here. The operator may delete backup files from Google Drive and may revoke OAuth access in Google Account connections. Revoking access prevents future API operations unless the operator authorizes the app again; it does not automatically delete files already stored.

Scope and changes

This site is a description of a personal backup workflow and is not a public service for other Google Drive users. This policy will be updated if the workflow's data handling materially changes.

Contact

Questions about this policy may be submitted to the repository's GitHub Issues page. Do not post passwords, OAuth tokens, or confidential data in a public issue.
