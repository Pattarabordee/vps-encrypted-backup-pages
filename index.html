Private backup utility

Encrypted PostgreSQL backups, stored offsite

VPS Encrypted Backup is a personal-use workflow that protects PostgreSQL database backup archives by encrypting them before transferring them from a privately managed VPS to the operator's Google Drive using rclone.

What it does

  • Creates PostgreSQL backup archives on a server managed by the operator.
  • Encrypts backup archives locally before upload. Encryption passphrases are managed separately from Google Drive.
  • Uploads and retrieves encrypted backup files through Google Drive, using rclone and Google OAuth.
  • Allows the operator to verify backup integrity and rehearse database restoration in an isolated environment.

Google Drive access

This workflow requests the https://www.googleapis.com/auth/drive.file scope. It is intended to access only Google Drive files created by, or explicitly authorized for, this OAuth application. It does not require full-drive access.

Not a public backup service. This website is informational. It does not provide accounts, a login form, a public upload portal, or access to the operator's backups.
